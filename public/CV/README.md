Coloca aquí los PDF definitivos: cv-es.pdf para español y cv-en.pdf para inglés.
El botón Imprimir CV / Print CV se activa únicamente para el idioma cuyo PDF esté disponible.
Después de añadirlos, ejecuta npm run build para incorporarlos a la versión final. Se abrirán en una pestaña nueva para verlos o imprimirlos desde el navegador.
No se incluyen archivos PDF vacíos ni ficticios.
